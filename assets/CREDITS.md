# Surface and sky sources

The game includes the following downloaded Poly Haven assets under **CC0**:

| Local prefix | Source |
|---|---|
| `materials/asphalt_*` | [Asphalt 02](https://polyhaven.com/a/asphalt_02) |
| `materials/concrete_*` | [Concrete Wall 007](https://polyhaven.com/a/concrete_wall_007) |
| `materials/ground_*` | [Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock) |
| `materials/paving_*` | [Pavement 02](https://polyhaven.com/a/pavement_02) |
| `sky/relay_clouds.hdr` | [Kloofendal 48d Partly Cloudy Pure Sky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) |

Surfaces contain 1K albedo, OpenGL normal and roughness JPEG maps. The panorama is a 2K HDR map. Files are bundled locally; the game makes no asset-service requests at runtime.

[Poly Haven asset license](https://polyhaven.com/license). Powered by Poly Haven for asset discovery/download through their API. Building, vehicle, street-detail, weapon and operator geometry is authored in the project's Godot scripts.
