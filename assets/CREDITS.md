# Surface and sky sources

The game includes the following downloaded Poly Haven assets under **CC0**:

| Local prefix | Source |
|---|---|
| `materials/asphalt_*` | [Clean Asphalt](https://polyhaven.com/a/clean_asphalt) |
| `materials/concrete_*` | [Concrete Wall 008](https://polyhaven.com/a/concrete_wall_008) |
| `materials/plaster_*` | [Painted Plaster Wall](https://polyhaven.com/a/painted_plaster_wall) |
| `materials/wood_*` | [Wood Planks](https://polyhaven.com/a/wood_planks) |
| `materials/floor_*` | [Concrete Floor](https://polyhaven.com/a/concrete_floor) |
| `materials/ground_*` | [Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock) |
| `materials/paving_*` | [Pavement 04](https://polyhaven.com/a/pavement_04) |
| `sky/relay_clouds.hdr` | [Kloofendal 48d Partly Cloudy Pure Sky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) |

Asphalt, concrete, plaster, paving, wood and floor contain original 4K albedo, OpenGL normal and roughness JPEG maps. Ground retains its 1K maps. Source URLs, physical dimensions and verified download MD5 checksums are recorded in `materials/sources.json`. The panorama is a 2K HDR map. Files are bundled locally; the game makes no asset-service requests at runtime.

[Poly Haven asset license](https://polyhaven.com/license). Powered by Poly Haven for asset discovery/download through their API. Building, vehicle, street-detail, weapon and operator geometry is authored in the project's Godot scripts.
